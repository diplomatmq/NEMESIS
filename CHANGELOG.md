# Changelog - NEMESIS Tower Game

## [v2.0.0] - Global Progress Update - 2024-10-07

### 🎯 Основные изменения

#### Глобальный прогресс игрока
- ✅ Прогресс больше не привязан к чату
- ✅ Один игрок = один прогресс на сезон
- ✅ Предметы, золото, уровень - глобальные
- ✅ HP и текущий враг - глобальные

#### Боевое состояние
- ✅ Бой сохраняется между чатами
- ✅ Начали бой в чате А → продолжите в чате Б
- ✅ Новая таблица `combat_state`

#### Детерминированная генерация врагов
- ✅ Все игроки встречают одинаковых врагов на одних этажах
- ✅ Боссы одинаковые для всех в сезоне
- ✅ Новый класс `SeededRandom` для генерации

#### Восстановление HP
- ✅ HP больше НЕ восстанавливается автоматически
- ✅ Восстановление только через зелья или переход этажа
- ✅ Новый сервис `PotionService`
- ✅ Зелья выпадают из врагов (20%) и боссов (100%)

#### Множественные чаты
- ✅ Первый чат = 100% наград
- ✅ Дополнительные чаты = 50% наград
- ✅ Новая таблица `chat_progress`

### 🆕 Новые функции

#### Команды
- `/potion` или `/зелье` - использовать зелье здоровья

#### Предметы
- Малое зелье здоровья - восстанавливает 30 HP
- Зелье здоровья - восстанавливает 50% HP
- Большое зелье здоровья - восстанавливает 100% HP

### 🔄 Изменения в существующих функциях

#### `/status`
- Показывает глобальный прогресс
- Показывает прогресс в текущем чате
- Показывает текущий бой
- Предупреждает о низком HP
- Показывает количество зелий

#### `/inventory`
- Отдельная секция для зелий
- Подсказка как использовать зелья
- Улучшенное отображение предметов

### 🗄️ Изменения базы данных

#### Новые таблицы
```sql
- combat_state (боевое состояние)
- chat_progress (прогресс по чатам)
```

#### Изменённые таблицы

```sql
- behavior_profiles (глобальное отслеживание)
```

#### Сохранённые таблицы
```sql

```

### 🔧 Технические изменения

#### GameService
- Полностью переписан `performAction()`
- Добавлена поддержка боевого состояния
- Добавлена система множественных чатов
- Интеграция с `PotionService`

#### CombatEngine
- `generateEnemy()` теперь принимает `seasonId`
- Детерминированная генерация через `SeededRandom`

#### BossSystem
- `getBossConfig()` и `generateBossEnemy()` принимают `seasonId`
- Детерминированная генерация боссов

#### LootService
- `generateLoot()` принимает `rewardMultiplier`
- Добавлена генерация зелий
- Интеграция с `PotionService`

### ⚠️ Breaking Changes

#### API изменения
```typescript
// Старое
PlayerProgressModel.find(userId, chatId, seasonId)
PlayerProgressModel.findOrCreate(userId, chatId, seasonId)

// Новое
PlayerProgressModel.find(userId, seasonId)
PlayerProgressModel.findOrCreate(userId, seasonId)
```

```typescript
// Старое
combatEngine.generateEnemy(floor)

// Новое
combatEngine.generateEnemy(floor, seasonId)
```

```typescript
// Старое
lootService.generateLoot(floor, isBoss)

// Новое
lootService.generateLoot(floor, isBoss, playerProgressId, seasonId, rewardMultiplier)
```
