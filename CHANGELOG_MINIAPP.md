# 🎮 Changelog: Mini App Integration

## Обзор изменений

Интегрировано мини-приложение Telegram (Emberspire/Ebashnya) с основным ботом NEMESIS Tower Game. Теперь игроки могут играть как в чате через бота, так и через полноценное мини-приложение.

## ✨ Новые функции

### 1. Команда `/admin` для администраторов

Новая команда предоставляет админам быстрый доступ к мини-приложению:

```typescript
/admin → Админ-панель с кнопками:
  - 🎮 Открыть мини-приложение (Web App button)
  - 📊 Статистика БД
```

**Файлы:**
- `src/bot/handlers/admin.ts` - добавлена функция `handleAdminCommand()`
- `src/index.ts` - зарегистрирована команда `bot.command('admin', handleAdminCommand)`

### 2. Выбор платформы при запуске сезона

Команда `/sstart` теперь спрашивает где начать сезон:

```
/sstart → Выбор:
  💬 Чат-игра
  🎮 Мини-приложение
  🌐 Оба варианта
```

При запуске сезона для мини-приложения в объявление добавляется ссылка на игру.

**Файлы:**
- `src/bot/handlers/admin.ts`:
  - Изменена функция `handleSeasonStart()` - добавлен выбор через inline клавиатуру
  - Добавлена функция `handleSeasonStartCallback()` - обработка выбора
- `src/game/SeasonService.ts`:
  - Добавлен параметр `mode: 'chat' | 'app' | 'both'` в метод `startSeason()`
  - Объявление о сезоне адаптируется под выбранную платформу
  - Добавляется ссылка на мини-приложение если выбран app/both
- `src/index.ts`:
  - Зарегистрирован обработчик `handleSeasonStartCallback` в callback queries

### 3. Docker интеграция мини-приложения

Мини-приложение запускается как отдельный контейнер параллельно с основным ботом.

**Файлы:**
- `docker-compose.yml`:
  - Добавлен сервис `miniapp` (Python 3.11)
  - Настроен volume `miniapp_data` для SQLite базы данных
  - Порт 8080 для доступа к веб-интерфейсу
  - Переменные окружения для мини-приложения
- `app/ebashnya/Dockerfile.miniapp`:
  - Новый Dockerfile для Python сервера
  - Базовый образ: python:3.11-slim
  - Установка Pillow для генерации карточек
  - Healthcheck endpoint
  - Экспонирование порта 8080

### 4. Расширенные переменные окружения

Добавлены новые настройки для мини-приложения:


## 🔐 Безопасность

### Аутентификация

Мини-приложение использует валидацию `initData` от Telegram:

1. Telegram передаёт подписанные данные через WebApp API
2. Python сервер проверяет HMAC подпись используя `BOT_TOKEN`
3. Только валидные запросы от Telegram обрабатываются

### Проверка админов

- Команда `/admin` доступна только ID из `ADMIN_IDS`
- Проверка в `handleAdminCommand()` и `handleSeasonStartCallback()`
- ID админов также используются в Python сервере для административных функций

## 🐛 Известные проблемы

1. **WEBAPP_URL должен быть HTTPS**
   - Telegram требует HTTPS для Mini Apps
   - Локальная разработка: используйте ngrok или локальный туннель
   - Продакшн: настройте Caddy или Nginx с SSL

2. **SQLite база данных отдельная**
   - Мини-приложение использует SQLite
   - Основной бот использует PostgreSQL
   - Нет синхронизации между базами (это нормально)

3. **Порты должны быть свободны**
   - Бот: порт 3000 (настраивается через PORT)
   - Мини-приложение: порт 8080 (настраивается через MINIAPP_PORT)
