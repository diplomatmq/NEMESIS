## 🚀 Как Применить Изменения на Сервере

### Вариант 1: Через Git (рекомендуется)

```bash
cd /opt/bots/NEMESIS

# 1. Создать бэкап (на всякий случай)
docker exec nemesis_postgres pg_dump -U postgres nemesis_game | gzip > backup_before_update.sql.gz

# 2. Получить обновления
git pull origin main

# 3. Создать .env.local с НОВЫМ токеном
cp .env.local.example .env.local
nano .env.local
# Замените BOT_TOKEN и DB_PASSWORD!

# 4. Защитить .env.local
chmod 600 .env.local
ln -sf .env.local .env

# 5. Сделать скрипты исполняемыми
chmod +x scripts/*.sh

# 6. Пересобрать и перезапустить
docker compose down
docker compose up -d --build

# 7. Проверить логи
docker compose logs -f bot
```

### Вариант 2: Ручное обновление файлов

Если git недоступен, скопируйте изменённые файлы вручную:

```bash
cd /opt/bots/NEMESIS

# Используйте scp, rsync или другой метод

# Затем выполните шаги 3-7 из Варианта 1
```

## 🔐 КРИТИЧЕСКИ ВАЖНО: Замена Токена

**Старый токен был скомпрометирован!** Необходимо:

1. **Открыть @BotFather в Telegram**
2. **Отправить:** `/mybots`
3. **Выбрать:** nemesis_robot (или ваше имя бота)
4. **Нажать:** "API Token" → "Revoke current token"
5. **Подтвердить** и **скопировать новый токен**
6. **Добавить в `.env.local`** на сервере:
   ```env
   BOT_TOKEN=НОВЫЙ_ТОКЕН_ЗДЕСЬ
   ```
7. **Перезапустить бота:**
   ```bash
   docker compose restart bot
   ```

## 🔄 Что Происходит При Первом Запуске

1. **PostgreSQL запускается** и ждёт готовности
2. **Redis запускается** и ждёт готовности
3. **Бот подключается** к PostgreSQL
4. **Проверяет существование** базы `nemesis_game`
5. **Если базы НЕТ:**
   - Подключается к служебной БД `postgres`
   - Создаёт `nemesis_game`
   - Логирует: "Database created successfully!"
6. **Если база ЕСТЬ:**
   - Логирует: "Database already exists"
   - **Данные сохраняются!**
7. **Выполняет миграции** (только новые)
8. **Запускает бота**

## 🆘 Если Что-то Пошло Не Так

### База данных не создаётся

```bash
# Создать вручную
docker exec -it nemesis_postgres psql -U postgres -c "CREATE DATABASE nemesis_game OWNER postgres;"
docker compose restart bot
```

### Бот не запускается

```bash
# Проверить логи
docker compose logs bot

# Проверить .env.local
cat .env.local | grep -v PASSWORD

# Пересоздать
docker compose down
docker compose up -d
```

### Потеряны данные

```bash
# Восстановить из бэкапа
./scripts/restore.sh backups/latest_backup.sql.gz
```

### Нужна полная очистка

См. `CLEANUP_INSTRUCTIONS.md` для безопасной очистки.
